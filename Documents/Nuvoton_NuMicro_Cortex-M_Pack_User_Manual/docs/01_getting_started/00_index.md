# Getting Started

This chapter describes what you need, how to install the extensions and how to open or create a NuMicro
project in Visual Studio Code.

- The required software, supported debug probes and how to connect the probe.
- How to install the extension pack and which extensions it includes.
- How to open a BSP sample project and which flash and debug items become available.
- How to start a new project from a blank CMSIS solution.
