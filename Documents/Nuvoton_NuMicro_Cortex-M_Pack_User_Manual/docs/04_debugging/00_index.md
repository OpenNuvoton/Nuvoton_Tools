# Debugging

This chapter describes how to start a debug session, change debug options, show peripheral registers and show
FreeRTOS task status.

- How to start a debug session in launch or attach mode.
- The pyOCD options that can be set in `launch.json`, such as probe UID and SWD clock.
- How to show peripheral registers by name with the device SVD file.
- How to set up a FreeRTOS project so the debugger can show task status.
