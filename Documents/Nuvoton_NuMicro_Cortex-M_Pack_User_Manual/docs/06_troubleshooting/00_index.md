# Troubleshooting

This chapter lists common problems and how to solve them.

- Problems with missing flash/debug configurations or a missing CMSIS-Toolbox.
- Errors and disabled buttons when flashing the application.
- Debug probes that cannot be found or opened.
- Debug sessions that do not start or do not stop at `main`.
- Failures when reading or programming CONFIG words.
- Companion extensions that keep being reinstalled.
