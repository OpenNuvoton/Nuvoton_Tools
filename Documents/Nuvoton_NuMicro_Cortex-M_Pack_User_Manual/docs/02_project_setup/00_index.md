# Project Setup

This chapter describes how to change the target device of the project, keep the linker script memory sizes
in step with it, check the CMSIS Solution settings and update the device pack.

- How to change the target device, what to do when a device is missing from the list, and how the linker script
  memory sizes are updated automatically or manually.
- How to check that the CMSIS view uses the Nuvoton flash and debug configurations.
- How to update the Nuvoton device pack (DFP) used by the project.
