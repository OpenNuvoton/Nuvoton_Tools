## Command Reference

Press **Ctrl+Shift+P** and type **Nuvoton:**.

| Command | Use |
|---|---|
| **Nuvoton: Configure CONFIG Words** | Read and program CONFIG words. |
| **Nuvoton: Select Device Model** | Change the device of the project. |
| **Nuvoton: Sync linker script memory sizes from cbuild-run** | Update linker script memory sizes. |
| **Nuvoton: Regenerate chip description** | Refresh device data after installing or updating a DFP. |
| **Nuvoton: Update workspace tasks.json for probe-rs** | Recreate the flash and debug tasks. |
| **Nuvoton: Update Task.json Content** | Make **Load application** in the CMSIS view use **Probe-rs Load**. |
| **Nuvoton: Add GDB Index to Program File** | Speed up debug start for the current application. |
| **Nuvoton: Check Extension Version** | Check and install the companion extensions. |
